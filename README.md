# Merry Christmas and Welcome to my Advent of Code repo!

### Here you will find my approaches to each AoC challenge year after year.

The repository is divided between the folders of the different years.
In each folder of the year you will find a folder for each day of the challenge.
Inside the daily folder you will find:
- two .txt files named example and input. In these files you will find the data provided by the statement of the example and the input respectively.
- two .ipynb files where you will find the challenge of the day posed and solved.
